# Daily Coding Challenges
---

This is a collection of my daily coding challenge solutions.

## Platforms

### LeetCode

LeetCode problems are organized by difficulty:

- **Easy**
- **Medium**
- **Hard**

### Codewars

Codewars problems are organized by Kyu rank:

- **8 kyu** — Beginner
- **7 kyu** — Beginner / Intermediate
- **6 kyu** — Intermediate
- **5 kyu** — Intermediate / Advanced
- **4 kyu** — Advanced
- **3 kyu** — Advanced
- **2 kyu** — Expert
- **1 kyu** — Expert
